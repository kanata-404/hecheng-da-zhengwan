# 合成大蒸丸

手机触屏图片合成小游戏，375×812 布局，十级照片玻璃球、增重 kg 计分和彩带庆祝。

## 在线试玩

[GitHub Pages 试玩](https://kanata-404.github.io/hecheng-da-zhengwan/)

[原站](https://melon-drop-lab-261119.liangzhenyuan24.chatgpt.site/)

## 运行与发布

`index.html` 包含完整游戏和内嵌图片，无需安装和构建。GitHub Pages 使用 main 分支根目录发布。

移动瞄准、松手投放，相同图片碰撞升级。键盘支持左右方向键与空格。堆叠顶部越过警戒线即结束本局。

## 统计

匿名访问和开始游戏事件发送到原站统计服务；该服务需要继续运行。记录访问次数、每天去重浏览器数、开始游戏访问次数及局数。最高纪录保存在各设备浏览器中。
